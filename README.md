# Hi there 👋

**I build tooling that makes AI coding agents behave like senior engineers** — they stop guessing,
remember what's fragile, and don't say "done" until verification actually ran.

🗣️ Español / English

---

### 🔧 What I'm working on

- **[claude-engineering-harness](https://github.com/anegri93/claude-engineering-harness)** — A
  Claude Code harness: a fixed engineering standard in every session, rules generated from a
  semantic read of the repo, a verification gate that runs real commands, and a living baseline
  of known risks.
- **[audit-repo](https://github.com/anegri93/audit-repo)** — Claude Code skill + manual checklist
  to answer, in minutes, whether an npm/pnpm/yarn supply-chain advisory affects your repo.
- **[agent-skills](https://github.com/anegri93/agent-skills)** — Reusable skills for coding
  agents (project bootstrapping and more).

### 🧠 What I care about

- Agent harnesses over prompt tweaks: context, rules and gates decide output quality.
- Verification that is real — a passing suite that tests nothing is worse than none.
- Supply-chain security and boring, reviewable diffs.
